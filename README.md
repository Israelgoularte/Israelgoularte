## Áreas de atuação

Desenvolvo agentes, integrações e ferramentas que conectam dados às rotinas de negócio.

- **IA aplicada** — agentes que consultam dados e usam ferramentas para apoiar análises e rotinas operacionais.
- **Automação e integrações** — fluxos de trabalho que conectam APIs, webhooks, CRMs, scripts e serviços sob medida.
- **Dados e operação** — pipelines de dados, consultas em PostgreSQL e dashboards para acompanhar indicadores.

## Projeto em destaque

### [Análise de Dados com IA](https://github.com/Israelgoularte/tcc_A_D_C_IA)

Meu TCC explora como registrar eventos de um CRM, consultar dados comerciais com um agente de IA e montar dashboards dinâmicos. O repositório reúne workflows, arquitetura e dados fictícios para reproduzir o cenário de teste.

**Tecnologias do projeto** · n8n, Kommo CRM, PostgreSQL e Docker.
